# Эксперт-Аудит — корпоративный сайт

Готовый стартовый проект на Next.js + TypeScript.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

## Страницы

- `/` — Главная
- `/services` — Услуги
- `/team` — О сотрудниках
- `/disclosure` — Раскрытие информации
- `/privacy` — Политика обработки персональных данных

## Что заменить перед публикацией

1. Реальный логотип.
2. ФИО, фотографии, должности, дипломы и сертификаты сотрудников.
3. Реальный список клиентов и разрешенные логотипы.
4. Актуальные сведения для страницы раскрытия информации.
5. Файлы годовой отчетности в `public/reports/`.
6. Финальный текст политики персональных данных после юридической проверки.
7. Контактные данные, если они изменились.
8. Настроить форму заявки и серверную отправку.
9. Добавить аналитику и cookie-уведомление в соответствии с фактической конфигурацией сайта.

## Важно

Тексты раскрытия и политики в проекте являются подготовленной структурой/шаблоном и не должны публиковаться без сверки с актуальными сведениями организации и применимыми требованиями законодательства.
