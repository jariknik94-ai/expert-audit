# 🏢 Эксперт-Аудит — корпоративный сайт

Корпоративный сайт ООО «Эксперт-Аудит», разработанный на **Next.js, React, TypeScript и SCSS Modules**.

Сайт представляет компанию, её услуги и специалистов, а также содержит информацию о клиентах, раскрытии информации, документах и контактных данных.

Подключена Яндекс.Метрика с отслеживанием переходов между страницами и основных действий пользователей.

* `click_contact`;

Также используются автоматические события GA4, включая `file_download`.

## 🔀 301-редиректы

При переносе сайта со старой версии на новую необходимо сохранить доступность существующих URL.

Для старых адресов предусмотрены следующие перенаправления:

| Старый URL        | Новый URL     | Код |
| ----------------- | ------------- | --- |
| `/aboutemployees` | `/team`       | 301 |
| `/about_us`       | `/disclosure` | 301 |
| `/privacypolitic` | `/privacy`    | 301 |

Поскольку production-версия сайта размещается на **VPS REG.RU**, редиректы будут настроены на уровне **Nginx**.

Пример конфигурации:

```nginx
location = /aboutemployees {
    return 301 /team;
}

location = /about_us {
    return 301 /disclosure;
}

location = /privacypolitic {
    return 301 /privacy;
}
```

Такой подход позволяет выполнить редирект до передачи запроса в Next.js.

## 🖥️ Production и деплой

Production-версия проекта планируется к размещению на **VPS REG.RU**.

Предполагаемая схема:

```text
Интернет
    ↓
Nginx
    ├── HTTPS
    ├── 301-редиректы
    └── reverse proxy
            ↓
        Next.js
            ↓
        npm start
```

Nginx будет использоваться для:

* обработки домена;
* HTTPS;
* SSL-сертификата;
* 301-редиректов старых URL;
* reverse proxy на Next.js;
* обработки входящих HTTP-запросов.
