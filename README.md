# 🏢 Эксперт-Аудит — корпоративный сайт

Корпоративный сайт ООО «Эксперт-Аудит», разработанный на **Next.js, React, TypeScript и SCSS Modules**.

Сайт представляет компанию, её услуги и специалистов, а также содержит информацию о клиентах, раскрытии информации, документах и контактных данных.

---

## 🛠️ Стек

| Технология                | Назначение                    |
| ------------------------- | ----------------------------- |
| ⚡ **Next.js 15**          | Фреймворк приложения          |
| ⚛️ **React**              | Компонентный UI               |
| 🔷 **TypeScript**         | Типизация                     |
| 🎨 **SCSS Modules**       | Стилизация компонентов        |
| 🧭 **Next.js App Router** | Маршрутизация                 |
| 🖼️ **next/image**        | Оптимизация изображений       |
| 🔤 **next/font/local**    | Локальное подключение шрифтов |
| 🎯 **React Icons**        | Иконки интерфейса             |
| ✨ **Manrope**             | Основной шрифт                |

## 🚀 Запуск проекта

### 📦 Установка зависимостей

```bash
npm install
```

### 💻 Режим разработки

```bash
npm run dev
```

После запуска сайт будет доступен по адресу:

**http://localhost:3000**

### 🏗️ Production-сборка

```bash
npm run build
npm start
```
