# 🏢 Эксперт-Аудит

Корпоративный сайт ООО «Эксперт-Аудит»: услуги, команда, раскрытие информации и контакты.

**Сайт:** [exspert-audit.ru](https://www.exspert-audit.ru/)

**Текущая версия:** 1.0.3 · [История релизов](https://github.com/jariknik94-ai/expert-audit/releases)

## 🛠️ Технологии

Next.js 15 (App Router), React 19, TypeScript и SCSS Modules. Для изображений и шрифтов используются `next/image` и `next/font/local`.

## 🚀 Локальный запуск

Требуются Node.js **20.19 или новее** и npm.

```bash
npm ci
npm run dev
```

Сайт будет доступен по адресу [localhost:3000](http://localhost:3000).

## ✅ Проверка и сборка

```bash
npm run check   # проверка типов и ссылок на локальные файлы
npm run build   # production-сборка
npm start       # запуск собранной версии
```

## 📁 Структура проекта

```text
app/         Страницы, маршруты, метаданные и секции главной страницы
components/  Общие компоненты и их стили
lib/         Данные сайта и функции аналитики
public/      Изображения, иконки и документы
scripts/     Скрипты проверки
```

## 📊 Аналитика и SEO

Подключены Google Analytics 4 и Яндекс Метрика. Логика событий находится в `lib/analytics.ts`, компоненты счётчиков — в `components/`. Для отчётов по событиям в Яндекс Метрике необходимо настроить соответствующие цели.

Метаданные страниц задаются через Next.js Metadata API; структурированные данные организации размещены на главной странице. Файлы `robots.txt` и `sitemap.xml` формируются Next.js.

## 🖥️ Развёртывание

Сайт размещён на VPS REG.RU за Nginx. При отправке изменений в ветку `main` GitHub Actions запускает проверки и сборку, затем развёртывает проверенный коммит на сервере. Nginx отвечает за HTTPS и перенаправления.

Конфигурация процесса: `.github/workflows/deploy.yml`. Во время развёртывания рабочая копия на сервере сбрасывается к опубликованному коммиту, а неотслеживаемые файлы в каталоге проекта удаляются.
