# Эксперт-Аудит — корпоративный сайт

Корпоративный сайт ООО «Эксперт-Аудит», разработанный на **Next.js + TypeScript + SCSS**.

Сайт предназначен для представления компании, услуг, сотрудников, клиентов, раскрытия информации и контактных данных.

## Стек

* Next.js
* React
* TypeScript
* SCSS Modules
* Next.js App Router
* `next/image`
* React Icons

## Запуск

Установите зависимости:

```bash
npm install
```

Запустите проект в режиме разработки:

```bash
npm run dev
```

Откройте в браузере:

http://localhost:3000

## Сборка

Для создания production-сборки:

```bash
npm run build
```

Для запуска production-версии:

```bash
npm start
```

## Страницы

* `/` — Главная
* `/services` — Услуги
* `/team` — Сотрудники
* `/disclosure` — Раскрытие информации
* `/contacts` — Контакты
* `/privacy` — Политика обработки персональных данных

## Основные разделы сайта

На главной странице представлены:

* информация о компании;
* основные направления деятельности;
* преимущества компании;
* порядок работы;
* клиенты;
* финальный блок с переходом на страницу контактов.

На странице сотрудников размещена информация о специалистах и доступные документы.

На странице услуг представлены основные направления деятельности компании.

На странице раскрытия информации размещены необходимые сведения и документы.

На странице контактов указаны:

* телефон;
* электронная почта;
* адрес офиса;
* расположение офиса на карте.

## Что необходимо проверить перед публикацией

1. Реальный логотип и favicon.
2. ФИО, фотографии, должности, дипломы и сертификаты сотрудников.
3. Список клиентов и наличие разрешений на размещение их наименований и логотипов.
4. Актуальность сведений на странице раскрытия информации.
5. Актуальность размещенных документов и годовой отчетности.
6. Текст политики обработки персональных данных после юридической проверки.
7. Контактные данные организации.
8. Ссылки на WhatsApp, Telegram, телефон и электронную почту.
9. Корректность адреса и расположения офиса на карте.
10. Работу всех внутренних и внешних ссылок.
11. Корректное отображение сайта на мобильных устройствах.
12. Настройку формы заявки, если она будет добавлена.
13. Подключение аналитики, если она будет использоваться.
14. Соответствие cookie-уведомления фактической конфигурации сайта.

## Документы

Документы, доступные пользователям сайта, хранятся в каталоге:

```text
public/documents/
```

Изображения и фотографии размещаются в:

```text
public/images/
```

При добавлении или замене документов необходимо проверить их названия и ссылки на соответствующих страницах.

## Важно

Тексты страницы раскрытия информации и политики обработки персональных данных являются подготовленной структурой проекта и должны быть проверены на соответствие актуальным сведениям организации и применимым требованиям законодательства перед публикацией.

Перед размещением сайта в production необходимо проверить все контактные данные, документы, ссылки, пользовательские уведомления и отображение сайта на мобильных устройствах.
